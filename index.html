설정하세요

  1. Google Cloud Console에서 프로젝트를 만들고 YouTube Data API v3를 사용 설정하세요.
  2. 사용자 인증 정보 메뉴에서 OAuth 클라이언트 ID(웹 애플리케이션)를 만드세요.
  3. 승인된 자바스크립트 원본에 http://localhost:4174 를 추가하세요.
  4. 발급된 클라이언트 ID를 아래에 붙여넣으세요.

클라이언트 ID는 이 브라우저에만 저장되며 외부로 전송되지 않아요.
